    沉淀团队知识
    上传发布规范、事故复盘或运维手册，可按服务关联。没有文档也能先体验评审。

    连接一次变更
    粘贴公开的 GitHub PR 链接。评审固定在当前提交；PR 有新提交时，请重新开始评审。

    持续对话，明确下一步
