## 使用与边界

1. 打开 `http://localhost:8080/`，上传适用的规范并等待入库。
2. 输入公开 PR 链接，点击“开始 PR 评审”，不需要额外提供服务名和版本号。
3. 如遇限流，等待提示的恢复时间，或仅在本机 `.env` 设置 `GITHUB_TOKEN` 并通过 `run-dev.cmd` 重启；不要把 Token 发到聊天或提交 Git。重启本身不会重置 API 配额。
4. 在同一会话追问具体发现；PR 更新后创建新会话。

本次没有真实私有仓库或生产发布验证，没有评论或合并 PR。私有仓库被后端主动拒绝，需要先实现应用认证与访问控制。长对话摘要通过可重复单元测试；本次真实模型验证为两轮，没有声称完成多小时对话或并发压测。仓库源码不会被执行，模型只收到已读取的资料。
