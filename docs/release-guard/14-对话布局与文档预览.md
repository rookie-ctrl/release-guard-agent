# 对话布局与文档预览

## 对话区

- 默认评审面板从最低 640px 增至 800px，桌面端收窄知识库侧栏与外边距，给对话留出更多宽度。
- 对话正文和输入框使用 14px 字号，输入框默认高度增加。
- 点击「专注对话」隐藏导航、统计、PR 设置和知识库，让当前会话占用主要屏幕；再次点击或按 Escape 恢复原布局和页面位置。
- 专注模式只改变页面布局，不创建新会话，也不停止正在执行的 Agent。

## 文档查看

- 每张文档卡片都有明确的「查看内容」按钮；点击文档名称或卡片空白区域也能打开内容弹窗，删除与重试按钮不会误触预览。
- HTML 中的 JS / CSS 引用带资源版本号，避免页面刷新后仍复用旧版脚本，后续前端更新时同步调整版本号。
- `GET /api/documents/{id}/content` 使用 Tika 从服务器保存的原文件提取文字，与向量化状态无关；等待解析、解析失败的文档也可以查看。
- Markdown 使用现有的安全 Markdown 渲染器，其他格式显示纯文本；「原始文本」可查看未经前端排版的提取结果。
- PDF / Word 预览只提供提取文字，不复现页码、图片和原始版式；扫描图片文档不保证能提取文字。
- 预览最多返回 100,000 个字符，超过时返回 `truncated=true`，界面明确提示下载查看完整内容。
- `GET /api/documents/{id}/download` 下载原始上传文件，保留文件名并使用附件响应。
- 两个接口只允许访问当前文档存储目录中的真实文件，校验规范化路径和符号链接解析结果；不存在或越界时返回 404。
- 下载使用 `application/octet-stream`、`nosniff` 和 `no-store`，不让上传文件作为网页执行。
- 弹窗请求带版本标记，关闭或切换文档后，旧响应不会覆盖新文档。

## 验证

- `DocumentControllerTest` 覆盖 Markdown、普通文本、Word、超长截断、原文件下载、未知文档、越界路径及文件缺失。
- 本地执行：`mvn17.cmd -Dtest=DocumentControllerTest test`。
- 服务重启后点击已有文档，检查预览、原始文本、下载，以及专注模式进入和退出。
